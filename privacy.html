grevberg-bot privacy policy

Last updated 2026-10-28.

grevberg-bot is a personal, self-hosted assistant run by one household for its own use. It is not available to the public.

Data accessed

With the account owner's consent, grevberg-bot accesses that owner's Google Calendar (scope https://www.googleapis.com/auth/calendar) to read, create and change events when the owner asks it to.

Use, storage and sharing

  • Calendar data is used only to answer the owner's own requests.
  • The OAuth token is stored only on the owner's private home server.
  • No data is sold, shared with third parties, or used for advertising.
  • Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Use the support email shown on the app's Google consent screen.
